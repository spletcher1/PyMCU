# OptoTest 5: Progressive ratio. The fly earns each Activation with more and more separate
# feeding bouts (Events). Once the Requirement is met, the LED lights for exactly ActivationMs.
#
# What to expect: touch and release a Well in separate bouts, pausing at least 0.1 s between
# them (EventGapMs, default 100 ms, is what separates one bout from the next). The 1st bout
# lights the LED for 1 s (FirstRequirement 1). The next Activation needs 3 bouts (Step 2 more),
# the one after that 5, then 7, and so on up to 20 (Cap). Bouts made while the LED is on do
# not count. The data file shows each Well's Requirement and Progress.
#
# Settings: ActivationMs is the light per Activation. Series Arithmetic grows the Requirement by
# Step after each Activation: FirstRequirement + Step x (k - 1) for the k-th Activation. Series
# Exponential (with Scale and Rate) is the Richardson and Roberts series instead. Acclimation
# is 0 here, so there are no closed-loop Activations first; OptoTest 6 shows them.
#
# Needs DFM firmware 4.0.0, which runs the ratio rules itself. PyMCU refuses it for older
# boards. ID: All makes every connected DFM run it.
